# 記念日

> 個人の試作・初版です。動作は参考情報で、保証はしません。

誕生日・結婚記念日・開業日などを登録すると、「あと何日」「今日で○日目」「次の節目(100日・1,000日・○周年)」を数えて、AIが一言添えます。個人の試作の初版で、参考情報です。

## 先に知っておいてほしいこと

- **日数の計算は付属のスクリプト(Python 3)がします。** AIの暗算ではありません。Pythonが無い場合は簡易モードになりますが、日数は目安でずれることがあります
- 追加のライブラリは要りません(Pythonに最初から付いているものだけで動きます)
- `SKILL.md` に対応しているAIツールで使える作りにしていますが、**動作確認は Claude Code(Windows)だけです。** ほかのAIツール・Mac・Linux は動く想定で、確認していません
- 登録した内容の正しさは入力次第です。**退院日・支払期限・契約更新日のように、見落とすと困る日の管理には使わないでください**(カレンダーなど別の手段をお勧めします)

## できること

- 登録の型は3つ: **毎年**(誕生日など)/ **起点**(その日から数える。付き合った日・開業日など)/ **両方**(結婚記念日など)
- 数字の面白さ: 100日目・1,000日目のようなキリ番、111・1,111のようなぞろ目、語呂(777・4649など。4649は「よろしく」の語呂合わせで、数量ではないためカンマなし)を見つけて理由を添える
- 近づくにつれた「次の一手」(計画→準備→直前→前日→当日)の候補を出す
- 命日など重い日は、茶化さず事実だけを静かに伝える(枠の調子を種別で切り替えます)
- 表示は文字の枠、または自分のPCで開くHTMLページ

## 安全性について(何をするか、全部書きます)

「安全です」と言い切るより、何をするかを並べます。気になる人はコードを読んでください(スクリプトは `scripts/anniv.py` の1本と、ページのひな形 `scripts/page.html` だけです)。

**やること**
- 登録した名前・日付・種別を `~/.claude/記念日/anniversaries.json` に保存する(保存先は環境変数 `ANNIV_HOME` で変えられます)
- 保存した内容から、日数や節目を毎回計算し直して表示する

**やらないこと**
- **インターネットへの通信は、スクリプトからは一切しません。** 外へ送るための仕組み(urllib・requests・socket など)は使っていません
- 設定ファイルや、記念日以外のファイルは読み書きしません

**ひとつだけ注意**
- 「ページで出す」機能のひな形(`scripts/page.html`)は、見た目のために Google Fonts(フォント)を読み込みます。ページを開く時にだけ、フォントの取得で外部への通信が起きます
- 家族の誕生日・命日などの実データでページを作り、AIツール側の公開ページ機能で公開すると、その内容が載ります。実データでの公開は、持ち主が決めた時だけにしてください

**消す** → `~/.claude/記念日/` フォルダを削除すれば、登録内容はすべて消えます

## 入れ方

このフォルダの内容(`SKILL.md` と `scripts/`)を、お使いのAIツールのスキル置き場に `記念日` という名前のフォルダで置きます。Claude Code なら `~/.claude/skills/記念日/` です。

あとは「記念日を登録して」と話しかけます。

## 使い方

| やりたいこと | 話しかけ方 |
|---|---|
| 登録する | 「記念日を登録して」(聞かれるのは名前と日付だけ) |
| 近い記念日を見る | 「近い記念日は?」 |
| 1件を詳しく見る | 「結婚記念日のこと詳しく」 |
| 面白い日を探す | 「面白い日を教えて」 |
| 消す | 「○○を削除して」 |

自己点検は `python scripts/anniv.py check` で実行できます(日数の計算が合っているかを確かめます)。
